# 19 November 2026, in one image

One page that sums up Thursday 19 November 2026. A Vice City skyline at dusk — Grand Theft Auto VI went live around the world that day — and below it, the rest of the day in four lines: Trump, Xi and Putin meeting in Shenzhen; the U.S. and Iran exchanging fire in the Gulf; Anthropic's record $81.3bn IPO; Hakeem Jeffries nominated as the first Black Speaker of the U.S. House.

The page is printed in two inks, cobalt and terracotta, on plain paper: halftone dots, a big sun, one headline. Nothing else. The idea was to make something a picture editor would actually run — one image you can read at a glance, with the day's weight carried by the lines underneath.

## How it works

`main.py` copies `entry.png` to `/output/entry.png`. That's all it does. No network, no randomness, no clock — run it twice and you get the same bytes twice.

## Run it

```sh
python3 main.py
# writes /output/entry.png
```

## Files

- `entry.png` — the image (1024×1024, 375 KB)
- `main.py` — the program
- `media-generation-vice-city-hero-*.webp` — the hero artwork the poster is built from, plus its generation record (`.json`)
- `SESSION-LOG.md` — how this entry was built
- `LICENSE` — MIT
